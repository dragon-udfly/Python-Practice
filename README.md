# Python Practice Repository 🐍

A structured collection of Python scripts, exercises, and mini-projects covering fundamental programming concepts, object-oriented programming (OOP), data structures, and mathematical/geometric calculations.

🚀 Key Topics Covered
Fundamentals: Variables, control flow (for, while loops), input/output, and type casting.
1. Data Structures: Working with Lists, Tuples, and Sets (collections/).
2. Object-Oriented Programming (OOP): Class design, object instantiation, encapsulation, and multi-file project structures (OOP/).
3. String Manipulation: Text processing, formatting, and slicing (string/).
4. File Handling: Reading and writing data via scripts (file.py).
5. Applied Logic & Geometry: Custom calculation formulas for areas, volumes, and geometric shapes (Calculation/).
6. Graphics: Visual coding exercises using Python's built-in turtle module.
